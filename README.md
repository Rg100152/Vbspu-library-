​⚡ The "Magic" Setup (One-Click Run)
​Don't want to deal with manual setups? Run this single command in your Linux/Mac terminal or Termux. It will automatically download the code, install requirements, and start the live server!
git clone https://github.com/Rg100152/VBSPU-CyberLib.git && cd VBSPU-CyberLib && pip install flask && python3 app.py
​Note for Windows Users: Open Command Prompt or PowerShell and use python instead of python3.
​🌟 Key Features
​🎨 Cyberpunk UI/UX: A dark, futuristic interface heavily utilizing Neon Green, Hot Pink, and Vibrant Orange with smooth glassmorphism effects.
​🎟️ Instant Digital E-Pass: Generates a real-time unique library pass with an animated scanning effect upon successful booking.
​📡 Live Terminal Tracking: Whenever a user books a pass on the website, the details (Name, Roll No, Course, Pass Code) are instantly logged/printed on the host's terminal.
​🗄️ Zero-Config Database: Uses SQLite to store all booking records locally without needing complex database installations.
​📱 Fully Responsive: Styled with Tailwind CSS to look flawless on both mobile and desktop screens.
